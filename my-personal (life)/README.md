# My Personal (life)

Started 2026.09.28 at Kate's request: "I think in the AI Brain we should probably build a personal folder with things like this."

This is where the personal side lives: travel, packing, trips, the dog, anything that isn't Kate Burda & Company business. Janice owns the logistics and Megan owns training and wellness.

**Not auto-loaded.** On purpose, this folder is not in `my-business (context)/`, so personal details don't get read into every business session. Agents open it when a task needs it.

## What's here

- `travel/packing-template.md` is the standing packing checklist: Kate, Pierce, the EV, and work gear. It's built from Kate's own `OneDrive/Personal/Travel.xlsx` format (date, city, event, day wear, evening wear, workout, and outfit counts by type).
- `travel/yyyy.mm.dd - <Trip> - Packing List.md` is one file per trip. Janice builds it from the calendar about 3 days before departure.

## Standing routine (Janice)

For any trip on the calendar (all-day city entries such as "Colorado" or "Michigan", flights, or "Start Driving" blocks), Janice builds the trip file 3 days out:
1. A day-by-day plan from the real calendar: city, what's happening, what to wear, workouts from Megan's plan
2. Outfit counts by type, the way Travel.xlsx does it
3. Pierce's list if he's coming
4. The car and charging plan if Kate is driving
5. Appointments to book before leaving, and what can be done from the car

Kate's own source files stay where they are in `OneDrive/Personal/`, including `Travel.xlsx` and `Michigan Trip.docx` (the EV route and charging stops). Link to them rather than copying.
