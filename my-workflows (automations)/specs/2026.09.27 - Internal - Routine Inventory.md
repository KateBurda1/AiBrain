## Skills vs routines

**A skill is the instructions. A routine is the alarm clock.** They are a pair, never duplicates. `janice-morning-brief` reads `my-skills/morning-brief/instructions.md` and follows it exactly, so deleting that skill breaks the 6:39am routine. Same for Wylie.

## Two traps worth knowing

**A routine's working folder is stored separately from the paths inside its prompt.** `megan-weekly-training-schedule` silently could not start for weeks because its working folder was `OneDrive-turningpointglobal.net/My-AI-Brain/My AI Brain`, dead since the OneDrive rename, even after the paths inside the file were fixed on 9/23. `update_scheduled_task` cannot change a working folder, only the prompt and schedule, so a broken one has to be deleted and recreated from a session rooted in a real folder. Symptom: "routine couldn't be started," or a `lastRunAt` that stops advancing.

**A routine must never write to `weekly-compass-data.json` while Kate has the Compass page open.** That page connects to the file directly and writes its whole in-memory copy back, so an outside edit gets reverted or duplicated. This happened 2026.09.27 and left two sets of workout blocks in one week. The Janice routine checks the file's timestamp and refuses to write if it was touched in the last 30 minutes.
