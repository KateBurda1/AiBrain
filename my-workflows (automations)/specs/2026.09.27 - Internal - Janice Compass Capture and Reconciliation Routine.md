## Known hazard: never write to the data file while Kate has it open

`weekly-compass-data.json` lives at `OneDrive-KateBurda&Company 2/Weekly Compass/`. The Compass HTML (`~/Downloads/weekly_compass_2.html`) connects to that file through the File System Access API and **writes its entire in-memory copy back**. It has no localStorage.

So if anything edits the file while Kate has the page connected, her next page-write silently reverts it, or both sets of edits end up duplicated. This happened on 2026.09.27: a write at 17:04 and Kate's page-write at 17:11 left two sets of workout blocks in the week of 9/28. **Rule: edit that file only when Kate is out of the page, or hand her the change to make in the page. Check the file's mtime before and after any write.**
