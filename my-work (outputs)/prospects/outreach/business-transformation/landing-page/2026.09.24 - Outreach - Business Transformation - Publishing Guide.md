# Built for the Climate: Publishing Guide

**For:** Kate, publishing on kateburda.com (WordPress)
**Files in this folder:**
- `wordpress-landing-page.html`: paste into the landing page
- `wordpress-thank-you-page.html`: paste into the thank-you page
- `tornado.jpeg` and `logo.png`: upload to your Media Library
- `index.html`: the full prototype, for reference only

**Addresses:**
- Landing page: `kateburda.com/built-for-the-climate`
- Thank-you page: `kateburda.com/built-for-the-climate/thank-you`

---

## Step 1: Upload the images (done: tornado and logo were already on the site, report PDF uploaded as media 902)

1. In WordPress, go to **Media > Add New** and upload `tornado.jpeg` and `logo.png`.
2. Open each one and copy its **File URL**. You'll paste these in Step 2.
3. When the report PDF is designed, upload it here too and copy its URL.

## Step 2: Create the landing page (done by Claude: draft page 900)

1. **Pages > Add New.** Title: *Built for the Climate*. Set the slug to `built-for-the-climate`.
2. In the page settings, pick your theme's **full width** or **blank** template if it has one. That hides the site menu, so nothing pulls people away before they download.
3. Add a **Custom HTML** block and paste in all of `wordpress-landing-page.html`.
4. In the pasted code, find and replace:
   - `TORNADO_URL` with the tornado File URL (it appears once)
   - `LOGO_URL` with the logo File URL (it appears twice)
5. Leave the line `PASTE THE ZOHO FORM EMBED CODE HERE` in place for now. Step 3 fills it.
6. Save as a **draft**.

## Step 3: Build the form in Zoho Forms (part of Marketing Plus)

**Zoho CRM is ready (done 2026.09.24):** five new fields exist on Contacts: **Content Downloaded, UTM Source, UTM Medium, UTM Campaign, UTM Content.** Lead Source already has a **Web Download** option.

1. In **Zoho Forms**, create a new blank form: *Built for the Climate: Report Download*.
2. **Visible fields, all required:** First Name, Email (label it "Work email"), Company. Keep it to three.
3. **Hidden fields:**
   - `content` (default value **Built for the Climate**)
   - `utm_source`, `utm_medium`, `utm_campaign`, `utm_content` (set each to fill from the page address, which Zoho Forms calls URL parameters)
4. **Integrations > Zoho CRM:** send to **Contacts**. If the email already exists, **update** the contact rather than creating a duplicate. Map the fields:
   - First Name to First Name, Email to Email, Company to Account Name (or a Company text field)
   - `content` to **Content Downloaded**
   - `utm_source`, `utm_medium`, `utm_campaign` and `utm_content` to the matching **UTM** fields
   - Lead Source set to the fixed value **Web Download**
5. **After submit:** send people to `https://kateburda.com/built-for-the-climate/thank-you/`.
6. **Email to the person who submitted:** subject "Your report: Built for the Climate". Body: one warm line from Kate plus the link `https://kateburda.com/wp-content/uploads/2026/09/built-for-the-climate-kate-burda-co.pdf`.
7. **Look:** button color `#D51067`, square corners, simple font.
8. **Share > Embed:** copy the embed code (the iframe or JavaScript version) and send it to Claude. Claude replaces the dashed "Zoho form goes here" box on the landing page draft (page 900) with it.

## Step 4: Create the thank-you page (done by Claude: draft page 903, noindex set)

1. **Pages > Add New.** Title: *Thank you*. Set its parent page to *Built for the Climate*, so the slug becomes `built-for-the-climate/thank-you`.
2. Use the same full width template. Add a **Custom HTML** block and paste in `wordpress-thank-you-page.html`.
3. Replace:
   - `TORNADO_URL` and `LOGO_URL` (same as Step 2)
   - `REPORT_PDF_URL` with the PDF's File URL
   - `BOOKING_URL` with your 20-minute booking link (done: https://kateburdacompany.zohobookings.com/5011447000000039045)
4. **Hide it from search.** In your SEO plugin's settings for this page, set it to **noindex**. You want people to reach it only after the form.

## Step 5: Set up search, and link it from your site (SEO title and description done; link from Insights still to do)

- **SEO title:** Built for the Climate: Why Transformations Miss the Top Line | Kate Burda & Co.
- **Meta description:** What 30+ senior leaders told us about why transformation rarely moves revenue, and what the leaders who hit the top line do differently. Free report.
- **Featured image:** the tornado.
- **Link to it** from your Insights page, so it's part of the site and helps search.

## Step 6: Tracked links for each piece

Use these links in the posts and emails, so Zoho knows which piece brought each person in:

| Piece | Link |
|---|---|
| 1, LinkedIn | `kateburda.com/built-for-the-climate/?utm_source=linkedin&utm_medium=social&utm_campaign=bt-series&utm_content=piece-1` |
| 1, Email | `...?utm_source=zoho&utm_medium=email&utm_campaign=bt-series&utm_content=piece-1` |
| 2 to 5 | Same, with `piece-2` to `piece-5` |

## Step 7: Test before publishing

1. Open the draft landing page on your phone and on your laptop.
2. Fill in the form with your own details.
3. Check that you landed on the thank-you page.
4. Check that the confirmation email arrived with the PDF link.
5. Check that the contact in Zoho CRM shows Lead Source *Web Download*, Content Downloaded *Built for the Climate*, and the UTM fields.
6. Then publish both pages.
