## Part 3: Workflow rule spec (for Tristan)

**Trigger:** Contacts, `Content_Downloaded` field is not empty (currently only "Built for the Climate" is possible).

| When this happens | Zoho does this |
|---|---|
| `Content_Downloaded` is set | Remove the contact from the Track 6 cadence. Set `Lead_Source` = Web Download (already possible as a fixed picklist value in a workflow rule, unlike in the Forms integration mapping). Start a short 2-step "downloaded" cadence (below). Create a task for Jack: "Follow up: downloaded [Content_Downloaded]." |
| Downloaded-cadence Day 2 | Email from Kate: "Anything in there land?" One line, one question, no pitch. |
| Downloaded-cadence Day 5, no reply | Send the Stage 4 message: "One question before any big commitment: your best quarter last year, were you right, or just lucky?" with the 20-minute booking link. |
| Contact books the 20-minute meeting (Calendly, `https://calendly.com/kate7792/new-meeting`) | Stop every cadence. Create a Deal. Alert Kate. |
| Contact replies to any email, any cadence | Stop that cadence (standard Zoho Cadence behavior, confirm it's switched on). |

**Known form gap to fix first (2026.09.24):** the Zoho Forms landing-page form has no field currently mapped to `Content_Downloaded`, so real downloads won't set it until that's fixed. See the [[2026.09.24 - Outreach - Business Transformation - Publishing Guide|Publishing Guide]]'s Step 3 addendum: add a hidden Single Line field, default value "Built for the Climate," and map it to `Content_Downloaded` in the Forms → CRM integration.
