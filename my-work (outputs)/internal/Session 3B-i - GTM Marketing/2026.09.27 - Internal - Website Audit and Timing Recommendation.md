## 2. kateburda.com — redundancy audit

### Headline numbers
- **Domain Power 1** / Domain Rating 13 / Domain Authority 16 — very low authority for a site with 327 backlinks / 23 referring domains, which itself is a symptom of the content problems below diluting the domain's own link equity.
- **Organic keywords: 2–5 total**, both non-commercial: "cazbah marketing" (position 25) and "joya burda" (position 12) — essentially brand-adjacent name queries, not service terms.
- **Monthly organic traffic: 0.** GSC confirms — no clicks/impressions returned for the property in the windows checked.
- **OTTO site audit (completed 2026-09-26):** 101 pages crawled, 1,468 issues found, site score 897.

### The redundancy itself — this is real, and it's structural, not keyword cannibalization

Because almost nothing ranks organically right now, this isn't two pages fighting over the same keyword in search results. It's a WordPress content-hygiene problem that's very likely holding traffic down in the first place:

**A. Orphan pages — the single biggest number.** OTTO's audit flags **59 of 101 crawled pages (58%) as orphaned** — no internal links point to them, so search engines can't reliably find or rank them. Paired with **97 of 101 pages flagged "not enough internal links,"** the site's internal link structure is close to non-functional. This alone would suppress rankings independent of anything else.

**B. Page-builder fragment pages, indexed as if they were real pages.** The crawl surfaces ~20+ URLs that are clearly leftover Divi/Elementor slide or hero-image fragments, not standalone content, e.g.:
- `/connection/hdrconnecthero-2/`, `/connection/hdrexplorehero-2/`, `/connection/hdrexplorehero-3/`, `/connection/hdrpathhero-3/`
- `/home/connect/`, `/home/connect-2/`, `/home/connect-3/`, `/home/explore/`, `/home/explore-2/`, `/home/explore-3/`, `/home/path/`, `/home/path-2/`, `/home/hdrhomepagehero-2/`
- `/origin/hdroriginhero/`, `/origin/hdroriginhero-2/`
- `/pathway/hdrpathhero-2/`, `/pathway/kateburda_path/`, `/pathway/where-you-win/`, `/pathway/2020-05-28_18-50-13/`, `/pathway/screen-shot-2020-10-16-at-9-46-38-am/`

These are consistent with **content_below_150_words (64 pages)** and **images_missing_alt (97 pages)** in the OTTO breakdown — thin, non-substantive pages diluting crawl budget and domain quality signals.

**C. Duplicate "Insights" pages.** Both `/insights/` and `/insights-2/` are live and indexed — worth confirming which one is current and 301-redirecting or removing the other.

**D. A cluster of near-duplicate, geo-stuffed local-SEO pages** — reads like an old, unfinished local-SEO experiment (possibly a prior agency or tool), targeting "Highland Village TX" with truncated, awkward titles:
- `/revenue-strategy-consulting-choosing-your-in-highland-village-tx/` (301, already merged — good)
- `/sales-transformation-consulting-sales-transfo-in-highland-village-tx/` (live, 200 — truncated title, reads unfinished)
- `/sales-transformation-consulting-b2b-sales-tra-in-highland-village-tx/` (404 — broken, should be cleaned up or redirected)
- `/measuring-roi-of-enterprise-sales-enablement-in-highland-village-tx/` (301, already merged into the clean version — good, this one's already been fixed)

**E. Broken parent/child and access issues worth a manual look:**
- `/contact-us/` currently returns **404** on the live https version (an older http variant was 200) — if this is really the current Contact page, that's a functional problem, not just an SEO one.
- `/optimizing-and-activating-revenue-within-the-tri-fecta/` is blocked (403) but its image sub-page is still live (200) — orphaned fragment outliving its blocked parent.
- Several pages return 403 (blocked, likely intentionally or via a security plugin — worth a quick confirm either way): `/case-studies/client-case-study/`, `/account-based-marketing-the-integration-of-sales-and-marketing-to-co-create-a-customer-centric-solution/` (plus its two image children), `/author/robert/`, `/pathway/prism/`, `/pathway-test/`.

**F. On-page issues at scale (OTTO, full site):** 81 pages with multiple H1 headings, 78 missing H2s, 56 missing recommended schema markup, 88 pending meta-keyword fixes (only 9% deployed), 97 images not in modern format (WebP/AVIF). Most of this is already inside OTTO's own fix queue (555 of 830 project-level fixes already deployed, 275 pending) — the redundancy items above are separate from what OTTO auto-fixes, since OTTO optimizes existing pages, it doesn't decide which pages shouldn't exist.

### What this doesn't show
No evidence of two *ranking* pages competing for the same commercial keyword — there isn't enough organic visibility left for that particular failure mode. The redundancy is upstream of that: content bloat and broken internal linking that's very likely part of *why* visibility is near zero.
